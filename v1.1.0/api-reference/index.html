    API reference

    Every public resource operation is listed below with its typed signature. Request and response models are exported from the top-level questblue package and documented in their resource modules.

    Clients

    questblue.QuestBlue

    Synchronous client for the QuestBlue API.

    paginate(path, *, method='GET', params=None, start_page=1, max_pages=10000, item_parser=None, item_selector=None)

    Lazily iterate a paginated endpoint while retaining raw page access.

    request(method, path, *, params=None, json=None, headers=None, timeout=None, max_retries=None, raw_response=False)

    Issue an authenticated request with safe, request-level overrides.

    Retries apply only to GET, HEAD, and OPTIONS. Mutating methods are always attempted once because QuestBlue does not document idempotency guarantees.

    questblue.AsyncQuestBlue

    Asynchronous client for the QuestBlue API.

    paginate(path, *, method='GET', params=None, start_page=1, max_pages=10000, item_parser=None, item_selector=None)

    Lazily iterate a paginated endpoint while retaining raw page access.

    request(method, path, *, params=None, json=None, headers=None, timeout=None, max_retries=None, raw_response=False) async

    Issue an authenticated request with sync-client-equivalent behavior.

    questblue.webhooks

    Framework-neutral models and parsing for QuestBlue messaging webhooks.

    InboundMessageEvent

    Bases: WebhookEvent

    An inbound SMS or MMS callback.

    MessageStatusEvent

    Bases: WebhookEvent

    An outbound message delivery-status callback.

    UnknownWebhookEvent

    Bases: WebhookEvent

    A forward-compatible callback whose shape is not yet published.

    WebhookEnvelope dataclass

    A parsed event plus content-free processing metadata.

    WebhookEvent

    Bases: QuestBlueModel

    Base callback model that preserves fields added by QuestBlue.

    WebhookKind

    Bases: str, Enum

    Webhook shapes published in the QuestBlue 2.3.2 contract.

    WebhookMessageType

    Bases: OpenStringEnum

    Published inbound message types, open to future provider values.

    WebhookVerificationRequired

    Bases: ValueError

    Raised when a framework helper is used without an explicit verifier.

    WebhookVerifier

    Bases: Protocol

    Application-defined callback verifier.

    QuestBlue does not publish a callback signature scheme. Implementations can enforce a reverse-proxy secret, mTLS identity, IP policy, or another control owned by the receiving application. They must raise on verification failure.

    __call__(headers, body)

    Verify the exact request bytes or raise an exception.

    parse_webhook(body, *, headers=None, verifier=None, kind=None)

    Verify and parse a QuestBlue callback without discarding unknown fields.

    The returned verified flag is true only when the supplied verifier completes successfully. Parsing alone makes no authenticity claim.
